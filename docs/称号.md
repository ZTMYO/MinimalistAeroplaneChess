# 进阶称号
同一件事按数值分档，只授予达到的最高一级；数值继续涨会再发一次升级后的那一级。
写成「A → B → C」的就是可以覆盖升级的进阶称号，括号里是门槛，一旦够到就锁定（中途断掉也算）。
